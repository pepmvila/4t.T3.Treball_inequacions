# Guia d’inequacions

Web estàtic per seleccionar el nom i descarregar la variant assignada.

## Publicació a GitHub Pages

1. Crea un repositori i puja index.html, .nojekyll i la carpeta pdfs a l’arrel. Descomprimeix aquest ZIP abans de pujar-ne el contingut.
2. A Settings > Pages, selecciona Deploy from a branch.
3. Tria main i / (root), i desa.
4. GitHub mostrarà l’enllaç del web quan acabi la publicació.

No cal instal·lar dependències ni executar cap compilació.
